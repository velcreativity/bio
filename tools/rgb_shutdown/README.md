# 화면 색 감지 자동 종료 도구

## 이게 뭔가요?

모니터 화면을 계속 지켜보다가, **정해 둔 색(RGB)이 화면에 나타나면 컴퓨터를 자동으로 끄는** 프로그램입니다.

- 기본: Windows 종료 명령으로 끕니다.
- 선택: 전원 버튼에 붙여 둔 **SwitchBot Bot(버튼 눌러주는 작은 기계)** 으로 전원 버튼을 눌러 끌 수 있습니다.
- 색이 감지되면 바로 끄지 않고, **"10초 후 컴퓨터가 꺼집니다"** 창과 큰 **취소** 버튼이 먼저 나옵니다.

## 설치 (처음 한 번만)

1. Python 3.10 이상을 설치합니다 (https://www.python.org/downloads/).
   설치 첫 화면 아래쪽의 **"Add Python to PATH"** 를 반드시 체크하세요.
2. 이 폴더(`rgb_shutdown`)에서 주소창에 `cmd` 라고 입력하고 Enter를 누르면 검은 창이 열립니다.
3. 아래 한 줄을 입력하고 Enter:

   ```
   pip install -r requirements.txt
   ```

## 사용 순서

### 1) 색과 위치 찾기: `start.bat --pick`

`start.bat --pick` 을 실행하면 0.5초마다 마우스 위치와 그 아래 색이 나옵니다.

```
위치 x=812 y=455   RGB=[255, 0, 0]
```

감지하고 싶은 곳에 마우스를 올려 놓고 **RGB 숫자**를 적어 두세요.
화면의 일부만 보고 싶다면 그 영역의 왼쪽 위 모서리 위치와 가로·세로 크기도 적어 둡니다.
끝낼 때는 Ctrl+C 입니다.

### 2) 설정 고치기: `config.json`

처음 `start.bat`을 실행하면 `config.example.json` 이 `config.json` 으로 복사됩니다.
`config.json` 을 메모장으로 열어 고치세요. (따옴표, 쉼표는 지우지 마세요.)

| 항목 | 쉬운 설명 |
| --- | --- |
| `target_rgb` | 찾을 색. 1)에서 적은 RGB 숫자. 예: `[255, 0, 0]` (빨강) |
| `tolerance` | 색이 조금 달라도 같은 색으로 인정하는 폭. 기본 10. 작을수록 정확하게 같은 색만 찾습니다. |
| `min_pixels` | 그 색의 점이 몇 개 이상 보여야 "나타났다"고 볼지. 기본 50. 작은 점 하나에 반응하지 않게 해 줍니다. |
| `region` | 감시할 범위. `null` 이면 주 모니터 전체. 일부만 보려면 `{"left": 100, "top": 200, "width": 300, "height": 100}` 처럼 적습니다. |
| `interval_sec` | 화면을 확인하는 간격(초). 기본 0.5 |
| `consecutive_hits` | 연속 몇 번 감지되어야 동작할지. 기본 3. 순간적으로 스친 색에는 반응하지 않게 해 줍니다. |
| `countdown_sec` | 종료 전 취소할 수 있는 시간(초). 기본 10 |
| `cooldown_sec` | 취소했거나 test 로 기록한 뒤 다시 감시를 시작하기 전에 쉬는 시간(초). 기본 30 |
| `action` | `"test"` (기록만 함), `"shutdown"` (Windows 종료), `"switchbot"` (SwitchBot 으로 끄기) |
| `switchbot` | SwitchBot 을 쓸 때만 입력 (아래 참고) |
| `save_evidence` | `true` 이면 감지 순간의 화면을 `evidence` 폴더에 사진(PNG)으로 저장 |

### 3) 확인하기: `start.bat --check`

지금 화면을 한 번만 검사해서 결과를 알려 줍니다.

- 감지되어야 하는 화면에서 **"예"** 가 나오는지,
- 감지되면 안 되는 평소 화면에서 **"아니오"** 가 나오는지 확인하세요.

### 4) 먼저 "test" 로 돌려 보기

`action` 이 `"test"` 인 상태에서 `start.bat` 을 실행합니다.
색이 나타나면 컴퓨터를 끄지 않고 **기록(`rgb_shutdown.log`)과 화면 사진(`evidence` 폴더)만 남깁니다.**
평소 사용하는 동안 엉뚱하게 감지되지 않는지 충분히 지켜보세요.

### 5) 실제 사용: "shutdown"

문제가 없으면 `config.json` 의 `action` 을 `"shutdown"` 으로 바꾸고 `start.bat` 을 실행합니다.
색이 연속으로 감지되면 카운트다운 창이 뜨고, 취소하지 않으면 컴퓨터가 꺼집니다.
카운트다운 창이 뜰 수 없는 환경이면 검은 창에 숫자가 나오며 Ctrl+C 로 취소합니다.

중지하려면 검은 창에서 Ctrl+C 를 누르거나 창을 닫으세요.

## SwitchBot 으로 끄기 (선택)

Windows 종료 명령 대신, SwitchBot Bot 으로 전원 버튼을 누르는 방식입니다.

1. SwitchBot Bot 을 PC 전원 버튼 위에 붙이고, 앱에서 등록합니다.
2. **클라우드 API는 SwitchBot Hub(허브 미니 등)가 있어야** 동작합니다. Bot 이 허브에 연결되어 있어야 합니다.
3. 토큰과 시크릿 얻기: SwitchBot 앱 > 프로필 > 환경설정 > **앱 버전을 10번 연속 탭** > **개발자 옵션** 에서 **토큰(token)** 과 **시크릿 키(secret)** 를 복사합니다.
4. `device_id` 얻기: 앱에서 Bot 의 기기 정보에 있는 ID(MAC 주소 형태, 예: `C1D2E3F4A5B6`)를 확인하거나, SwitchBot API의 기기 목록(`GET /v1.1/devices`)으로 확인합니다.
5. `config.json` 에 입력합니다.

   ```
   "action": "switchbot",
   "switchbot": {
     "token": "복사한 토큰",
     "secret": "복사한 시크릿",
     "device_id": "기기 ID"
   }
   ```

6. `start.bat --test-switchbot` 를 실행하면 Bot 이 한 번 눌립니다. 응답에 `"statusCode": 100` 이 보이면 성공입니다.
   **PC 전원이 켜진 상태에서 눌리면 컴퓨터가 꺼질 수 있으니, 저장할 작업이 없을 때 시험하세요.**

`config.json` 에는 비밀 키가 들어 있으니 다른 사람에게 보내거나 인터넷에 올리지 마세요.
(이 저장소에서는 `config.json` 이 자동으로 올라가지 않게 제외되어 있습니다.)

## 주의사항

- **종료되면 저장하지 않은 작업은 사라집니다.** 중요한 작업은 수시로 저장하세요.
- 평소 화면에 같은 색이 자주 나온다면 오작동할 수 있습니다.
  `tolerance` 를 줄이고, `min_pixels` 와 `consecutive_hits` 를 늘리고, `region` 으로 범위를 좁혀 주세요.
- 반드시 `--check` 와 `"test"` 로 먼저 확인한 뒤 `"shutdown"` 을 쓰세요.
- 동작(종료/Bot 누르기)을 한 번 하고 나면 프로그램은 스스로 끝납니다. (Bot 이 전원 버튼을 두 번 누르지 않게 하기 위함)
- 기록은 `rgb_shutdown.log`, 감지 순간 사진은 `evidence` 폴더에 있습니다.

## Windows 시작 시 자동 실행

1. 키보드에서 `Win + R` 을 누르고 `shell:startup` 을 입력한 뒤 Enter. 시작프로그램 폴더가 열립니다.
2. 이 폴더의 `start.bat` 을 마우스 오른쪽 버튼으로 끌어다가 시작프로그램 폴더에 놓고 **"여기에 바로 가기 만들기"** 를 선택합니다.
3. 다음에 Windows 를 켜면 자동으로 감시가 시작됩니다.
   (`config.json` 의 `action` 이 제대로 설정되어 있는지 먼저 확인하세요.)
