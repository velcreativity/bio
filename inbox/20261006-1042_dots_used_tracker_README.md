# 중고상품 검색·거래상태 추적기

Python 3.10 이상, Windows/macOS/Linux에서 실행하는 CLI 초안입니다.
당근·번개장터·중고나라 검색 URL 템플릿, 네이버 카페·기타 쇼핑몰을 추가하는 설정 인터페이스를 제공합니다.
**네 플랫폼 실서비스의 검색/거래상태 추출을 모두 검증한 완제품은 아닙니다.**
사이트별 상세페이지 구조, 로그인 권한, 당근 지역과 카페 주소에 따른 현장 설정/검증이 남아 있습니다.

## 설치·실행

파일을 같은 작업 폴더에 두고 터미널에서 실행합니다.

```bash
python -m pip install playwright
python -m playwright install chromium
python 20261006-1042_dots_used_tracker.py init
```

생성된 `config.json`의 `keywords`를 실제 상품명으로 바꿉니다.

```json
"keywords": ["맥북 프로 M4 Pro", "맥북 프로 M5 Pro"]
```

그다음 실행합니다.

```bash
python 20261006-1042_dots_used_tracker.py login
python 20261006-1042_dots_used_tracker.py run
```

`login`은 본인이 브라우저에서 로그인하고 당근 지역을 선택하는 단계입니다.
로그인이 불필요하면 생략할 수 있습니다. 로그인 세션은 로컬 프로필에 유지됩니다.
같은 프로필을 이용하는 두 프로그램을 동시에 실행하지 마세요.
`headless`를 `false`로 설정하면 수집 중 브라우저 화면도 확인할 수 있습니다.

## 지역·사이트 설정

- 당근: 검색 페이지 주소의 `in` 값을 해당 source의 `region`에 입력합니다. 지역 이름과 식별자가 포함될 수 있으므로 실제 주소 값을 사용합니다. 값이 없으면 지역 선택 화면만 나올 수 있습니다.
- 번개장터·중고나라: 기본 템플릿은 초기값입니다. 실제 검색 페이지 주소가 다르면 `search_url`을 수정합니다. 상품명 부분만 `{keyword}`로 둡니다.
- 네이버 카페: 기본 비활성입니다. 대상 카페의 실제 검색 URL을 `search_url`에 입력하고 `enabled`를 `true`로 바꿉니다. 접근 권한이 있는 계정으로 먼저 로그인합니다. 공개 검색에 나타나지 않는 글까지 보장하지 않습니다.
- 기타 쇼핑몰: 기본 비활성입니다. `search_url`, 상품 상세 URL 패턴인 `item_url_regex`, 정확한 도메인 목록인 `allowed_hosts`를 설정하고 활성화합니다.
- 사이트별 상태 라벨을 못 찾으면 `status_selector`에 **대상 상품에만 속한 상태 표시 요소**의 CSS selector를 지정합니다. 추천상품 영역이나 전체 `body`를 지정하지 마세요.
- 가격이 누락되면 `price_selector`에 대상 상품 가격 요소의 CSS selector를 입력합니다. 현재 자동 가격 추출은 상품 JSON-LD와 product:price:amount 메타값에 한정됩니다.
- 검색 결과가 0개라고 바로 매물이 없다고 판단하지 않습니다. `search_runs.csv`를 확인하고, 실제 주소·권한·링크 패턴을 점검합니다.

기본 수집은 검색당 최대 40개, 스크롤 3회입니다. 모든 페이지를 자동 탐색하는 전수 수집이 아닙니다. 설정값을 조정할 수 있으며 페이지 번호 방식의 사이트는 별도 어댑터가 필요합니다.
키워드 매칭은 입력 문자열 포함 방식입니다. 다른 띄어쓰기·약어는 별도 키워드로 추가하세요.

## 판정 원칙

| 결과 | 근거 |
|---|---|
| 거래가능 | 대상 상품의 판매중/거래가능 라벨 또는 해당 상품의 JSON-LD InStock |
| 예약중 | 대상 상품의 예약중 라벨 |
| 판매완료 | 판매완료/거래완료/판매종료 라벨 또는 해당 상품의 SoldOut/Discontinued |
| 품절 | 품절 라벨 또는 해당 상품의 OutOfStock |
| 삭제/페이지없음 | HTTP 404/410. 경로 변경 가능성도 있으므로 판매완료와 구분 |
| 미확인 | 상태 근거 없음, 충돌, 접근 제한, 로그인 필요, 연결 오류, 상품 외 페이지로 이동 |

본문에 '판매완료 아님'이라고 쓰여 있거나 추천상품이 판매완료라고 표시된 것을 그대로 판정에 쓰지 않습니다.
기본 DOM 방식은 h1 인근의 짧은 독립 라벨만 사용하지만, 사이트 구조에 따라 추천 영역이 가까이 있을 수 있어 실매물 검증과 selector 조정이 필요합니다.
구매 버튼이나 채팅 버튼이 있다는 이유만으로 거래가능이라고 확정하지 않습니다.
검색에서 사라진 매물도 보존하고 상세페이지를 다시 확인합니다.
접속 오류 이후 마지막으로 검증한 상태는 `last_verified_state`로 보존합니다. 현재 `state`는 미확인일 수 있습니다.
이전에 거래가능이었던 매물을 실제로 판매완료로 확인하면 변경 이력을 기록합니다.
미확인에서 같은 상태로 회복된 경우를 새로운 거래상태 변경으로 기록하지 않습니다.
판매자가 실제 거래 가능 여부를 갱신하지 않은 매물까지 확인할 수는 없습니다.

## 결과 파일

`used_tracker_data/`에 저장됩니다.

- `all_items.csv`: 전체 최신 확인 결과. 확인 시각, 가격, 근거, 마지막 검증 상태 포함.
- `filtered_items.csv`: 가격·제외 키워드 조건을 적용한 결과.
- `available.csv`: 현재 명시적으로 거래가능이 확인된 매물.
- `changes.csv`: 검증된 상태가 달라진 이력.
- `search_runs.csv`: 플랫폼/키워드별 발견 수, 검색 실패 사유.
- `all_items.json`: 전체 최신 결과 JSON.
- `items.sqlite3`: 매물, 키워드 연관, 모든 확인 이력, 변경 이력 저장.
- `snapshots/`: 검색/상세페이지 HTML 및 추출 데이터. 관찰 이력에 snapshot 경로 연결.

CSV는 Excel에서 한글이 잘 열리도록 UTF-8 BOM으로 작성됩니다.

가격·제외 키워드는 수집 후 내보내기에 적용합니다. 조건을 바꾸고 아래 명령으로 재수집 없이 다시 조회합니다.

```bash
python 20261006-1042_dots_used_tracker.py export
```

가격이 확인되지 않은 매물은 가격 필터 적용 결과에서 제외되지만 전체 결과에는 남습니다.
같은 URL은 중복 저장하지 않습니다. 플랫폼이 다른 동일 상품은 자동 병합하지 않습니다.
재확인은 가장 오래 확인한 기존 매물부터 최대 300개입니다. 새 검색 매물은 별도로 확인합니다.
설정의 `recheck_limit`로 조절하세요.

## 반복 실행

`run`은 한 번 수집하고 종료합니다. 매일/매시간 실행하려면 PC의 작업 스케줄러나 cron에서 같은 명령을 호출하세요.
현재 버전은 변경사항을 파일에 기록하며 카카오톡·이메일 알림을 보내지 않습니다.

## 검증과 현재 한계

```bash
python 20261006-1042_dots_used_tracker.py selftest
```

판정·근거 충돌·다른 상품의 JSON-LD 제외·접근 제한·일시적 오류 후 회복·상태 이력·CSV 내보내기·카페 URL 식별 테스트 5개 통과.
Python 구문 컴파일 확인.
실서비스 4종의 로그인 후 검색 및 상태 전환은 검증하지 않았습니다.
이 환경에서 브라우저 설치가 실패하여 브라우저 통합 실행 검증은 완료하지 못했습니다.
따라서 초기 실행 시 `search_runs.csv`, 실제 매물 상태, 저장된 상세페이지를 대조해야 합니다.

사이트가 데이터를 렌더링하는 데 더 오래 걸리면 `render_wait_ms`를 늘립니다. 기본 1.8초는 모든 사이트의 로딩 완료를 보장하지 않습니다.
페이지/selector 구조 변경이나 로그인 만료가 발생하면 설정과 어댑터를 갱신해야 합니다.
프로필 및 원본 페이지에는 계정 관련 정보가 포함될 수 있으므로 공유 파일에 넣지 않습니다.
