# 벨크리에이티비티 유료 사주 서비스 전환 진단

## 결론과 먼저 할 일

서비스 방향은 결제 후 자동 풀이를 제공하고, 고객이 더 알고 싶을 때 사람이 추가 작성하거나 상담하는 2단계 방식으로 정해졌습니다. 현재 사이트의 강점은 사주·관상·성명학·풍수를 연결한 설명과 시각적 이야기입니다. 공개 이용 경로는 긴 설명을 읽고 카카오 채널로 문의하는 방식에 가까워, 상품 소개에서 결제와 자동 결과까지 이어지는 경로를 별도로 설계해야 합니다.

권고는 기존 설명을 “사주 이해하기” 영역에 보존하고, 첫 화면에는 자동 풀이의 대상·결과 샘플·총액·제공 시간·시작 버튼을 두는 것입니다. 1단계는 단건 자동 리포트 1개로 시작하고, 결과 페이지에서 선택형 추가 해설·상담으로 연결합니다. 2단계를 별도 유료 상품으로 둘지는 가격·범위와 함께 정해야 합니다.

### 우선 결정할 세 가지

- 단계별 범위: 자동 풀이의 포함 내용과 사람이 추가 작성·상담할 내용, 추가 비용 여부

- 구매 약속: 1건의 가격, 포함 내용, 제공 시간, 수정 가능 범위, 다시보기 기간

- 운영 조건: 사이트 제작 방식, 사업자 상태, PG 심사 가능 여부, 문의와 환불 담당

관찰은 실제 공개 화면이나 공식 문서에서 확인한 사실입니다. 권고는 개선 설계입니다. 미검증은 로그인·결제·유료 결과·소스코드·서버·보안·성능처럼 이번 검토에서 확인하지 않은 항목입니다. 미검증을 장애나 부재로 단정하지 않습니다.

## 권장 구매와 결과 제공 흐름

확정된 방향은 1단계 결제 후 자동 풀이와 2단계 선택형 사람 추가 해설·상담입니다. 아래는 그 방향을 구현하기 위한 권고이며, 현재 사이트에 같은 기능이 구현돼 있다는 뜻은 아닙니다.

### 1단계 결제 후 자동 풀이

1  상품 소개: 누구의 어떤 질문을 다루는지, 결과 목차와 샘플, 총액, 단건 구매 여부, 제공 시간과 다시보기 기간을 보여줍니다.

2  정보 입력: 계산에 필요한 출생일, 양력·음력, 윤달 여부, 출생시간과 “모름”을 받습니다. 성별·출생지 등이 필요하다면 목적과 보정 기준을 설명하고, 이름은 필요한 경우에만 받습니다.

3  구매 전 확인: 입력 요약과 수정 버튼, 포함 결과, 최종 금액, 제공 시점, 환불 조건을 한 화면에 모읍니다. 필수 동의와 선택 항목을 구분합니다.

4  주문과 결제: 서버에서 상품·금액·주문번호를 생성합니다. PG 결제창에서 돌아온 뒤 서버가 승인 상태와 금액을 검증합니다.

5  생성과 결과: 결제 완료 → 생성 중 → 완료 또는 재처리 필요 상태를 구분합니다. 창을 닫아도 작업을 계속하고, 완료 결과는 저장합니다.

6  다시보기와 지원: 로그인 또는 검증된 연락처로 본인 주문을 복구합니다. 오류·지연 시 같은 주문에서 지원과 환불로 이어지게 합니다.

### 2단계 선택형 추가 해설과 상담

자동 결과의 각 항목에 “이 부분 추가로 질문하기”를 두고, 추가 서면 해설과 실시간 상담을 구분합니다. 포함 범위·납기 또는 예약 가능 시간·추가 가격 여부를 먼저 확인한 뒤 신청하게 합니다. 유료 추가 상품으로 운영한다면 자동 리포트와 별도 주문으로 관리하고, 서면 해설의 수정 범위와 상담의 일정 변경·노쇼 기준을 각각 정합니다.

자동 결과는 그 자체로 완결된 유료 상품이어야 합니다. 추가 요청에는 해당 결과 항목과 질문 맥락을 미리 채우되, 고객이 출생정보를 확인·수정하게 합니다. 상담자는 담당 주문에 필요한 정보만 보도록 권한을 제한하고, 외부 상담자라면 위탁·제3자 제공 관계와 필요한 안내·동의를 검토합니다. 별도 구매 확인 없이 추가 과금하지 않습니다.

실시간 상담은 가능한 시간·상담자·방식을 결제 전에 확인하고, 결제 성공 시 예약을 확정하도록 권합니다. 자동 결과를 열람했다는 이유만으로 아직 제공하지 않은 별도 상담의 환불까지 제한하지 않도록 두 주문의 상태와 정책을 분리합니다.

### 결과 페이지에 포함할 항목

입력정보 요약과 오류 문의, 결과 목차, 생성일과 제공 범위, 해석의 한계, 다시보기 기간, 고객지원 경로를 둡니다. 출생정보나 결과 본문을 주소창·분석 도구로 보내지 않고, 주문번호만으로 타인 결과를 열 수 없게 합니다.

## 결제와 개인정보 출시 체크리스트

### PG 계약과 결제 운영

- 상품 형태·가격·샘플·제공 시간·환불정책을 정한 뒤 PG에 사주 상품의 심사 가능 여부를 확인합니다. 포트원 업종 안내에서 토스페이먼츠·KCP 등은 심사 후 확인 대상으로 분류되며 승인을 보장하지 않습니다.

- 한 PG로 시작하면 직접 연동이 단순할 수 있습니다. 여러 PG가 필요하면 포트원을 검토하되, PG 계약·상품 심사가 별도로 필요하다는 점을 반영합니다.

- 서버 결제 검증, 주문별 중복 방지, 결제 상태 동기화, 비밀 키의 서버 보관을 준비합니다. 결제 후 통신이 끊기면 PG 상태를 확인한 다음 재결제를 안내합니다.

- 운영자는 주문 검색, 생성 실패 재처리, 결과 재전달, 환불과 처리 기록을 다룰 수 있어야 합니다. 자동 재시도에도 이중 결제·이중 생성·이중 환불이 없어야 합니다.

### 개인정보와 판매 조건

- 수집 목적·항목·보유기간·파기·처리업체를 실제 운영에 맞게 정합니다. 회원가입과 카카오 상담은 수집 경로가 다르므로 각각 확인합니다. 불필요한 실명·상세 주소·사진·주민등록번호는 받지 않는 방향을 권합니다.

- 해외 AI API나 호스팅을 쓰면 전송되는 데이터, 저장·학습 활용 여부와 국외 이전의 법적 근거·고지·동의 요건을 검토합니다. 출생정보나 결과 본문은 일반 분석 이벤트에 넣지 않습니다.

- 거래기록과 사주 원본·결과를 구분해 보관합니다. 거래기록의 법정 보존기간이 모든 출생정보와 결과를 일괄 장기 보관하라는 뜻은 아닙니다. 화면의 다시보기 약속과 실제 삭제 일정을 일치시킵니다.

- 사업자·연락처·해당 신고 정보, 가격, 제공 방법과 시기, 환불 조건을 표시합니다. 사업자등록과 통신판매업 신고의 적용·면제 여부는 실제 운영 형태로 확인합니다.

- “맞춤 사주라 무조건 환불 불가”라는 문구는 피합니다. 디지털콘텐츠 제공 개시와 청약철회 제한 요건, 샘플 제공, 공급 개시 기록을 검토하고 최종 정책은 전문가 확인을 받는 편이 안전합니다. 상담 상품은 별도 기준을 정합니다.

이 항목은 출시 준비를 위한 확인 목록입니다. 법률 적합성이나 PG 승인에 대한 판단·보증은 아닙니다.

| 문의·지연·오입력·환불을 누가 처리할 것인가 | 고객에게 안내할 답변 시간과 제공 책임을 실제 운영 가능하게 만듭니다. |

### 판매 공개 전 반드시 확인할 시나리오

- 정상 구매: 자동 풀이의 입력·승인·생성·재열람 완료. 추가 서비스 신청 시 범위와 가격을 확인하고 별도 주문·접수로 연결

- 중단과 반복: 결제 취소, 결제 후 창 닫기, 새로고침, 뒤로가기, 중복 클릭·알림 이후 올바른 상태 유지

- 실패와 환불: 승인 후 생성 실패, 제공 지연, 중복 결제 문의, 환불 완료와 고객 안내 기록 확인

- 접근 권한: 다른 계정이나 주문번호 추측으로 타인의 입력·결과를 볼 수 없는지 확인

- 내용과 화면: 잘못된 날짜, 음력·윤달, 시간 모름, 해외 출생, 긴 이름, 작은 화면과 키보드 조작 확인

계산 검수 권고: 선택한 만세력·절기·시간대 경계 기준을 문서화하고, 동일 입력에 동일한 계산값이 나오는지 사례별로 대조합니다. AI를 해설에 쓰더라도 만세력 값은 검증된 계산 로직에서 제공하고 자유 생성에 맡기지 않습니다. 실제 계산 알고리즘과 코드는 이번에 검사하지 않았습니다.

### 검토 범위와 해석상의 한계

이번 진단은 공개 화면과 공식 상품·정책 자료를 다뤘습니다. 회원가입, 실결제, 환불 실행, 유료 결과의 품질, 서버·소스코드·보안·성능은 검증하지 않았습니다. 따라서 결제·결과 관련 항목은 현재 장애 보고가 아니라 출시 조건과 향후 시험 계획입니다. 실제 판매 전에는 승인된 시험 절차로 결제와 취소를 확인해야 합니다.

비교 서비스의 가격·정책은 변경될 수 있습니다. 보유기간, 제공 범위, 환불 문구는 다른 서비스에서 복사하기보다 실제 상품과 처리 방식에 맞게 정해야 합니다. 건강·투자·관계의 결과나 풀이의 정확도를 보장하는 표현은 사용하지 않는 방향을 권합니다.
