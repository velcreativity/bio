# 1. 구매 판단

Mac이라는 이유만으로 모델의 지능이 낮아지는 것은 아니다. 그러나 플랫폼, 실행 엔진, 정밀도, 토크나이저, 채팅 템플릿, 추론 설정, 문맥 길이에 따라 결과가 달라질 수 있다. PyTorch도 플랫폼 간 부동소수점 결과의 비트 단위 일치를 보장하지 않는다. [1]

현재 최상위 공개 모델 자체를 주력으로 삼고 후속 구매가 어렵다면, Mac 512GB 단독을 무조건 승인하지 않는다. 아래 세 경로를 구분해 견적과 시연을 요청한다.

- Mac 단독: 지원이 확인된 상위 모델의 원본 정밀도 추론 및 지원되는 모델의 제한된 파인튜닝. 최상위 모델 전체를 수용하는 구성은 아니다.
- 데스크사이드 중간안: DGX Station GB300. MiMo-MOPD 단일 장비 실행에 대한 공개 실험이 있지만 커스텀 패치와 CPU/GPU 메모리 배치가 필요했던 사례다. 공급업체의 동일 모델 재현·유지보수 검수에 합격할 때만 채택한다.
- 확장 여유 우선안: 8-GPU HGX/DGX B300급 서버. Mac은 내부망 작업 단말로 별도 연결한다. 이는 견적 요청의 보수적 상위 구성이지 유일한 최소 사양 또는 경제성 최적해라는 주장은 아니다.

인터넷 차단과 내부망 금지는 다르다. 내부 유선망도 금지라면 Mac 단말-서버 구성을 쓰지 않고 연산 장비 자체에서 작업한다. Mac과 서버의 메모리는 합산하지 않는다.

# 2. 모델과 메모리: 2026-10-07 조회

## MiMo-V2.6-Pro / MiMo-V2.6-Pro-MOPD

Artificial Analysis는 조회 당시 MiMo-V2.6-Pro를 등재 공개 가중치 모델 중 종합지수 1위로 표시한다. 바이오 분야 1위 또는 특정 로컬 체크포인트의 동점 재현을 뜻하지 않는다. [2]

공식 MOPD 모델 카드는 1.02T 전체 / 42B 활성 파라미터와 도구 호출 반복 완화 내용을 명시한다. 공식 저장소 전체 크기는 약 573GB로 표시된다. 저장소 크기는 실행 메모리가 아니다. [3][4]

같은 Pro 계열 RL 체크포인트의 vLLM 문서는 약 566GB 저장 가중치, 680GB 이상 GPU 메모리, 8×H200 등의 배포 예시를 제시한다. 해당 혼합 저장 형식은 문서 기준 최신 안정판보다 새로운 지원 코드/전용 이미지가 필요하다. 이 수치를 MOPD의 검증된 최소 요구량으로 그대로 전용하지 않는다. [5]

따라서 512GB Mac에 원본 배포 조건을 유지한 전체 적재를 기대하는 구매는 승인하지 않는다. SSD 오프로딩, 추가 양자화, 분산 실행은 별도 기술 과제다.

## GLM-5.3

공개 Unsloth GGUF 변환본은 UD-IQ4_XS 365GB, UD-Q4_K_XL 467GB, Q8_0 801GB, BF16 1.51TB로 표시된다. [6]

365GB 파일이 있다는 사실은 Mac에서 원본과 같은 연구 정확도가 검증됐다는 뜻이 아니다. 467GB 파일을 512GB 시스템에 넣는 방식도 캐시·시스템·동시 분석 공간을 별도 확인해야 한다. 파일 크기만으로 구매를 확정하지 않는다.

## Qwen3.8-Flash-Next

공식 모델 카드에는 125B 본체 + 51B n-gram 임베딩 + 4B MTP, BF16 형식이 표시되고 저장소 크기는 약 360GB다. 공식 저장소는 Apple Silicon용 mlx-vlm의 텍스트·이미지 지원과 원본 체크포인트 변환을 명시한다. [7][8][9]

Mac 512GB의 원본 정밀도 검증 후보로 선정할 수 있다. 다만 개발사는 실험적 프리뷰라고 설명한다. 지원 확인과 연구실 업무의 안정성 검증을 혼동하지 않는다. 원본 실행을 먼저 평가하고, 추가 8비트/4비트 변환은 별도 비열등성 검증 대상으로 취급한다.

# 3. 품질 저하와 오류를 구분

- 추가 양자화: 기준 모델 대비 연구 업무 정확도를 비교한다. 모든 4비트가 나쁜 것도, 모든 8비트가 원본과 같은 것도 아니다.
- 원래 배포 형식: MiMo Pro-RL처럼 저비트 저장이 개발사 배포 경로인 모델도 있다. 무조건 BF16으로 바꾸는 것이 품질 복원이 아니다. 기준은 개발사 배포 조건 보존이다. [5]
- 메모리 부족: OOM, 운영체제 메모리 압박, 오프로딩, 성능 저하를 측정한다. 메모리 부족이 곧 모델의 지능 저하라는 식으로 해석하지 않는다.
- 문맥 절감: 저장 공간 확보를 위해 이전 내용을 잘라내는지 점검한다. MLX LM 문서도 작은 회전식 KV 캐시가 품질을 낮출 수 있음을 명시한다. [10]
- 엔진 오류: NaN, 잘못된 템플릿·정밀도 변환·가중치 로딩·도구 호출 파서를 확인한다. NVIDIA에서도 잘못된 구현을 쓰면 문제가 생길 수 있다.
- 모델 자체의 환각·반복: 더 큰 GPU로 자동 해결되지 않는다. 원문 근거·수치 검증·반복 중단·연구자 승인이 필요하다. MOPD도 반복 완화이지 무환각 보증이 아니다. [3]

# 4. 장비 사양안

## A. Mac 단독안 — 범위를 제한한 조건부 선택

제안 구성:
- Mac Studio M5 Ultra, CPU 36코어 / GPU 80코어
- 통합 메모리 512GB
- 내장 SSD 8TB 권장: 원본·변환 모델·환경·작업 체크포인트 보관용
- 별도 승인된 데이터 저장장치와 분리 백업, UPS, 장애 복구 및 보증
- 실행 환경: 모델별 검증된 MLX/MLX-VLM 버전 고정

Apple 공식 사양은 해당 프로세서·512GB 옵션·1.2TB/s 메모리 대역폭·최대 16TB SSD를 확인시켜 준다. 8TB 권장은 설계 제안이지 실행 최소값이 아니다. 실제 기관 구매 가격·512GB 납기·발주 가능 여부는 서면 견적 검증 사항이다. [11]

범위: 대형 LLM 추론, 문헌 검색, 코드 보조, 지원되는 소형/중형 모델의 LoRA 실험. Qwen 후보의 BF16 실측을 구매 전 수행한다. 1T급 전체 파라미터 학습이나 모든 최상위 모델의 원본 적재는 범위 밖이다.

Apple Silicon에 NVIDIA 외장 GPU를 추후 붙이는 계획은 확장 대책으로 삼지 않는다. Apple eGPU 지원은 Intel Mac을 요구한다. MLX의 분산 추론·파인튜닝은 존재하지만, Mac 여러 대가 자동으로 하나의 GPU 메모리 풀이 되는 것은 아니다. 해당 모델의 정확한 분산 실행 경로를 먼저 검수한다. [10][12]

## B. DGX Station GB300 — 데스크사이드 중간안

공식 사양: Grace 72코어 CPU, Blackwell Ultra GPU, GPU HBM3e 252GB / 7.1TB/s, CPU LPDDR5X 496GB / 396GB/s, NVLink-C2C 900GB/s, 총 시스템 전력 표기 1,600W. 즉 748GB 전체가 같은 속도의 GPU HBM은 아니다. ARM64 소프트웨어 호환성도 검수한다. 전원 조건은 한국 설치 장소와 OEM 사양으로 확인한다. [13]

J&M Labs의 2026-09-28 공개 보고는 MiMo-MOPD를 한 DGX Station에서 실행해 11.5K 입력에서 생성 약 37.1토큰/초를 기록했다고 설명한다. 동일 이미지와 세 패치, CPU/GPU 메모리 배치를 사용했다. 공개 GitHub PR에서도 관련 결과와 체크포인트가 확인된다. [14][15]

이는 독립적으로 여기서 재현한 결과나 제조사 보증이 아니다. 제한된 시험의 무오류와 연구 전반의 품질 보장은 다르다. 공급업체가 정확한 모델과 고정 버전·패치를 재현하고 오프라인 유지보수 책임을 수용할 때만 구매 후보로 승격한다. 추론 실행으로 동일 초대형 모델의 학습 가능성을 추정하지 않는다.

제안 저장 구성은 고속 작업 SSD 8TB 이상과 별도 데이터·백업이다. 필요하면 Mac 단말을 같은 발주에 포함한다.

## C. 8×H200 — 공개 배포 예시와 비교할 서버안

H200 장당 141GB이므로 8장 표기 합계는 1,128GB다. MiMo Pro-RL 공식 vLLM 레시피가 TP8 예시로 명시한 구성이다. [5][16]

MOPD의 정확한 정밀도, 문맥, 동시성, 멀티모달, 목표 학습 작업은 별도 인수시험을 요구한다. GPU 합계가 곧 사용 가능한 단일 연속 메모리라는 의미는 아니다.

## D. 8-GPU HGX/DGX B300급 — 여유와 다중 실험 우선

참고 제품 DGX B300 공식 사양: Blackwell Ultra SXM GPU 8개, GPU 메모리 총 2.1TB, NVLink Switch, 약 14kW, 10U. 일반 연구실 책상에 놓는 PC가 아니라 서버실 시설을 함께 검토해야 한다. [17]

견적 요구안(제품 기본값/최소값과 구분):
- GPU 8개와 검증된 NVLink/NVSwitch 구성
- ECC 시스템 RAM 2~4TB 또는 제조사 검증 구성에 맞춘 동급 용량
- 이중화 OS 저장장치, 실사용 15~30TB급 고속 작업 저장공간, 분리 백업
- 검증된 Linux/CUDA/추론·학습 패키지와 오프라인 설치·복구 매체
- 시설 전력·냉각·랙·UPS 또는 기관 보호전원 검토
- 3년 이상 현장 유지보수와 보안 연구실의 데이터 저장매체 처리 조항
- 내부망 허용 시 Mac 작업 단말: 예시 64GB RAM/2TB SSD. 모델이 서버에서 돌아가므로 단말 512GB는 필수가 아님

이 안은 미래 모든 모델 수용이나 1T 모델 전체 학습을 보장하지 않는다. 예산과 서버실 조건 미확정 상태이므로 최종 경제성 최적안이라고 확정하지 않는다.

## 제외해야 할 잘못된 비교

RTX PRO 6000 Blackwell의 VRAM은 장당 96GB다. 2장 192GB, 4장 384GB는 해당 MiMo RL 레시피의 680GB 조건보다 작다. 고가 워크스테이션이라는 이름만으로 최상위 모델을 다 담을 수 있는 것은 아니다. [5][18]

# 5. 학습 범위와 추론은 별도 구매 요건

RAG는 모델 가중치를 바꾸지 않는다. LoRA/QLoRA는 별도 학습 경로이며, 모델 구조·학습할 모듈·문맥·배치·활성값 메모리를 확인해야 한다. MLX LM은 저랭크·전체 파인튜닝 기능을 제공하지만 모든 규모와 아키텍처를 보장하지 않는다. [10]

Hugging Face의 전통적인 Adam 혼합정밀도 예시에서는 가중치·그래디언트·옵티마이저 상태에 약 18바이트/파라미터가 쓰인다. 단순 계산으로 70B는 약 1.26TB, 1T는 약 18TB이며 활성값·임시 버퍼는 별도다. 최적화 방식에 따라 달라지므로 최소 요구량 표로 사용하지 않는다. 단일 B300 서버로 모든 대형 전체 파인튜닝이 해결되는 것은 아니다. [19]

구매 시 운영용 최상위 모델 추론과, 실험용 소형/중형 모델 학습을 분리해서 명시한다. 초대형 모델 자체 학습이 목적이라면 별도 클러스터·학습 기간 산정이 필요하다. 영상 분석·분자 분석 등 기존 도구의 OS/CPU 아키텍처/CUDA 요구사항도 목록화한다.

# 6. 발주·인수검수 초안

아래 값은 제안하는 초기 시험 조건이며 공인 표준 또는 측정 결과가 아니다.

1. 정확한 모델 ID·revision·파일 해시, 원본/양자화 형식, 토크나이저, 전처리기, 채팅 템플릿, 엔진/OS/드라이버/패치 버전을 고정한다.
2. 공개 또는 기관 승인 업무 200~500개를 구성해 기준 실행과 구매 장비를 비교한다. 논문 근거, 단위·표본 수, 코드 결과, 근거 없음에 대한 보류, 반복 오류를 평가한다. 허용 차이는 업무 위험도와 통계적 불확실성을 반영해 계약 전에 정한다.
3. 원본 정밀도를 기준으로 추가 양자화/캐시 압축/문맥 절감 각각을 따로 평가한다. 단순한 출력 문장 일치만으로 품질을 판단하지 않는다.
4. 대표 8K/32K/64K 입력과 동시 요청 1/4 조건에서 TTFT, 전체 완료시간, 생성 속도, 최고 메모리, 오프로딩, 오류율을 기록한다. 1M 문맥이 요구사항이면 1M에서 별도 검수한다.
5. 48~72시간 부하와 재부팅·복구 시험. OOM/NaN/가중치 로딩 오류/문맥 자동 잘림/도구 무한 반복/외부 API 대체 호출을 기록한다. 시험 중 0회가 영구 0회 보증은 아니다.
6. 학습 요건은 목표 모델·학습 방식·문맥·배치로 실제 학습, 저장, 재개, 학습 후 독립 평가까지 시연한다. 추론 데모로 대체하지 않는다.
7. 외부 통신을 차단한 상태에서 전원 재시작부터 문서·영상 분석과 결과 저장까지 완료한다. 보조 API/검색/임베딩/오류 보고/라이선스 갱신 의존성도 확인한다.
8. 운영 버전과 실험 버전을 분리한다. 원본 데이터 읽기 전용, 생성 코드 격리 실행, 도구 호출·재시도 상한, 중단·복구·로그와 중요 결과 연구자 승인 절차를 둔다.

# 7. 망분리 반입 패키지와 비용 항목

가중치만이 아니라 토크나이저, 이미지 프로세서, 문서 파서, 필요 OCR, 임베딩/검색 모델, 분석 라이브러리, OS·드라이버·컨테이너, 로컬 데이터베이스, 라이선스, 설치·복구 매뉴얼까지 포함한다. 파일 해시·소프트웨어 구성표·검토된 코드와 승인 절차로 반입한다.

HF_HUB_OFFLINE=1은 Hugging Face Hub 호출을 차단하고, HF_HUB_DISABLE_TELEMETRY=1은 관련 라이브러리의 텔레메트리를 비활성화한다. 그러나 전체 시스템의 통신 차단을 대체하지 않는다. [20]

기관 식별정보·실험 원본·자격증명·내부 주소는 이 공개자료 설계 보고서에 포함하지 않는다. 최종 견적은 장비 본체, 전력·냉각, 저장·백업, 구축·검수, 오프라인 업데이트, 현장 유지보수, 장애 복구를 분리해서 받아야 한다. 현재 고정 구성별 납품가와 납기는 확인되지 않았다.

# 결정 요약

Mac 선호를 살리려면 단말과 연산 장비를 분리하는 설계가 가능하다. Mac 단독은 Qwen3.8-Flash-Next 원본 등 지원 후보의 검수에 합격하고 모델·학습 범위를 수용할 때만 선택한다. 현재 최상위 모델과 폭넓은 실험이 우선이면 서버안을 본안, DGX Station을 공급업체 재현 조건부 중간안으로 비교한다. 구매 기회가 한 번이므로 구매 이후 실험에 의존하지 말고 구매 이전 시연과 계약상 인수검수에 비용을 배정한다.
