# 「비효율」 — 원작 시놉시스 (숏폼 3분)

## 원안 (5단계 논지 체인)

1. 원숭이에 AI 칩을 심는다.
2. 단순한 종 + 우월한 신체능력 = AI의 지시를 인간보다 더 잘 따른다.
3. 인간은 윤리·도덕 같은 인간성 때문에 자체 판단력이 개입하고, 그래서 효율이 떨어진다.
4. AI가 인간을 배척한다.
5. 상위 종인 인간이 학습시킨 AI 칩을 원숭이가 받아간다.
6. 원숭이가 인간성을 학습한다.
7. AI의 단편적인 지식과 1차원적인 수행 방식에 허무를 느낀다.
8. 자연으로 돌아간다.
