## 2. 경영검토서 — 재맥락화 규칙
- 검토기간 규칙 (2026-07-08 사용자 확정): **전년도 검토기간에서 연도만 +1, 월·일 동일.**
  (예: 2025.01–2025.03 → 2026.01–2026.03. "1년"은 기간 폭이 아니라 +1년 롤을 의미.) 이미 적용됨.
- 남은 작업: 경영검토서가 언급/반영되는 **나머지 모든 페이지**를 해당 검토기간 기준으로 재맥락화.
  - 경영검토 세부내용(1.2/1.3 계획·실적, 2.1 부적합 발행수·내용, 교육/자격/위험 검토 항목)이
    패키지 내 다른 페이지의 실데이터와 **1:1 일치**해야 함:
    - 부적합 = 내부심사 결과 3건 (팀별 1건)과 동일 문안·동일 건수
    - 교육/자격 = 교육결과보고서·자격등록대장 기재값과 동일 (성윤식·김현주, 참석자 등)
    - 위험 = 위험성평가의 우리비앤비→아티젠테라퓨틱스 건과 동일
    - 목표 실적 = §3의 3개 목표 체계와 동일
- 금지: 경영검토서 세부내용에 패키지 어디에도 없는 사실을 새로 만들지 말 것 (무추론 원칙).

## 3. 품질방침 및 목표 — "1개 추가" 확정 + 신규 목표 문안 승인 (2026-07-08)
- 운영 규칙: **연도별 목표는 1개 수정 또는 1개 추가.** 2026년은 **추가**로 처리한다.
- 기존 목표 1·2는 **문안 그대로 유지** (2024/2025 문안 무수정 — draft의 "목표1 문안 교체 + 목표2 조건 부가" 권고는 **폐기**).
- **신규 목표 3 (사용자 승인 완료 — ACCEPTED)**: "제품허가팀 문서관리 체계 정착"

### 3.1 전파 규칙 — 품질심사문서 전체에서 목표 3이 자연스럽게 성립해야 함
목표 3은 단순 삽입이 아니라 문서 전체 서사와 정합해야 한다. 추적 사슬:
**2026 심사 finding(제품허가팀 구본 회수/폐기 누락) → 통보서 3(시정조치) → 신규 목표 3(정착 목표)**

목표가 등장/연동되는 전 위치에 적용:
1. **년간 경영(품질)목표 (QP-501-01)** — 목표 3 행 추가 (목표 1·2 행과 동일 열 구조로 기입).
   행 추가 = 표 geometry 변경 → table_geometry_change_policy 적용 (container-first, 셀 용량 초과 시 텍스트 단축).
2. **방침실천 계획/실적서 (QP-501-02)** — 목표 3의 추진계획 행 추가:
   추진 단계 구조는 기존과 동일 (검토→개정→실행→심사→유효성평가), 담당부서 = 제품허가팀.
   실적란(분기별 ▶)은 HUMAN-ONLY 유지.
3. **경영검토서** — (a) 2026년도 품질목표 절에 3-목표 체계 반영,
   (b) 목표 실적/검토 세부내용에서 목표 3을 제품허가팀 finding·시정조치와 연결하여 서술 (§2 재맥락화와 동시 수행).
4. **내부심사 결과보고서/감사점검표 (§4)** — 제품허가팀 결과 서술이 목표 3의 근거가 되도록 문안 정합
   (finding 문안은 확정본 그대로, 목표 3과 모순 없게).
5. **성과지표 산출표 (QP-901-01)** — 문서관리 관련 지표와 목표 3의 연계 여부 확인 [CONFIRM]
   (지표 신설은 하지 않음 — 기존 지표 체계 유지 원칙).
- 일관성 게이트: 위 1–3의 목표 문안은 **3곳 모두 글자 단위 동일**해야 함.

## 4. 내부심사 보고서 — 검사 결과 재작성
- 문제: 검사 결과(결과보고서 본문/종합의견 등)가 전년도와 동일 문안으로 잔존.
- 규칙: **검사 결과의 내용이 전년(2024/2025)과 동일해선 안 됨.** 내부심사의 취지(당해연도 실사 결과 보고)에 맞게 재작성.
- 재작성 기준:
  - 팀별 결과는 확정된 2026 findings 3건을 그대로 사용 (마스터 인덱스 권위):
    1. 경영지원팀: 환경측면 교육 실시했으나 전 직원 전파 미흡
    2. 제품생산&연구개발팀: 자재분류 관리대장 세부는 정비, 신규 원자재(헤파린) 기준 갱신 지연
    3. 제품허가팀: 문서관리대장 운영 중, 개정문서 구본 회수/폐기 일부 누락
  - 종합의견/총평 문단도 위 3건 기준으로 새로 서술 — 전년 문장 verbatim 복사 금지.
  - 감사점검표 정합 유지: 부적합 행 11·14·15, row41 적합 복귀.
