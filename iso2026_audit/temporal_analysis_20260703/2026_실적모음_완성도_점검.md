## C. 근본 제약
- 완전한 환경실적모음은 V4에 없음. 환경실적 2025.hwp(바이너리 HWP)에 있으며 클라우드에서 열 수 없음.
- 두 파일의 누락분은 모두 **폼(표/페이지) 추가** 작업 = 원시 XML 재조립 불가(방금 crash 원인).
  Hancom COM(코덱스/Windows)로 원본에서 InsertFile 후 확정 데이터 기입해야 안전함.

## D. 코덱스 실행 지시 (Windows/Hancom)
1. 환경실적 2025.hwp → HWPX 변환 (Hancom SaveAs).
2. 환경실적모음_2026 = 변환본에서 전 환경폼 확보 → 2026 날짜/용어/이상진·성윤식 적용
   (년도 롤포워드 스펙 적용).
3. 품질실적모음_2026 = 현재 파일 + QP-802-02/QP-902-02 폼 InsertFile → b9 데이터 기입.
4. 각 파일 저장 후 crash 검증(열림 확인), 이후 최종 검토.
