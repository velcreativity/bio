# 작업: HWPX 헤더·본문 표 레이아웃 정규화

대상 파일: `<파일 경로 입력>` (HWPX, 폼별 섹션 구조, 섹션마다 머리말 1 + 꼬리말 1)

## 절대 규칙 — 하나라도 위반하면 저장하지 말고 중단 후 보고
1. **내용 수정 금지**: 셀·문단 안의 글자·숫자·날짜를 한 글자도 생성/수정/삭제하지 않는다.
   레이아웃 속성(attribute)만 수정한다. 작업 전후 `<hp:t>` 텍스트 멀티셋이 동일해야 한다.
2. **count-assert**: 모든 문자열 치환은 사전에 발생 횟수를 세고, 기대치와 다르면 중단한다.
3. **재포장 규칙**: 원본 zip의 엔트리 순서·압축방식(DEFLATED/STORED)을 그대로 복제한다.
   `mimetype`이 첫 엔트리 + STORED. 디렉토리 엔트리 금지. `zip -r` 절대 금지.
4. 편집한 섹션의 `<hp:linesegarray>…</hp:linesegarray>`는 전부 제거한다 (한컴이 재계산).
5. `landscape="NARROWLY"` 섹션은 **가로 용지**다. 유효 영역 계산 시 width↔height를 바꿔
   쓴다. 이 플래그를 삭제·변경하지 않는다 (QP-401 이슈현황표 섹션들이 해당).
6. U+F0000 이상의 PUA 문자는 한컴 전용 구분선 문자다. 깨진 글자로 오판해 삭제 금지.
7. 새 스타일(charPr/paraPr/borderFill) 생성 금지. 기존 id만 참조한다.

## 1단계 — printable region 측정 (섹션별, 결과를 표로 보고)
각 `Contents/sectionN.xml`의 `<hp:pagePr>`·`<hp:margin>`에서:
- 세로(`landscape="WIDELY"`): `printW = width − left − right − gutter`, `printH = height − top − bottom`
- 가로(`landscape="NARROWLY"`): `printW = height − left − right − gutter`, `printH = width − top − bottom`
- `bodyW = printW`, `bodyH = printH − header밴드 − footer밴드`

기준 파일 검산값 (다르면 측정 오류이니 재확인):
- A4 세로 59528×84188, 여백 L/R 2836 → printW **53856** (EP 섹션은 L/R 2834 → 53860)
- 가로 섹션(QP-401): printW **73132** (84188−7088−3968)
- footer 밴드는 전 섹션 **3400**

## 2단계 — 머리말(헤더) 표: 중앙정렬 + 영역 내 수용
머리말(`<hp:header>` subList) 안의 표에 대해:
- 표의 `<hp:pos …>`: `horzAlign="CENTER"`, `horzOffset="0"`으로 변경
  - 단, `treatAsChar="1"`인 표는 horzAlign이 무시된다 → 헤더 표는
    `treatAsChar="0" flowWithText="1" allowOverlap="0" vertRelTo="PARA" vertAlign="TOP"
    horzRelTo="COLUMN" horzAlign="CENTER"`로 통일
- 머리말 문단의 들여쓰기 공백 run(`<hp:t>` 안이 스페이스뿐)은 제거 (중앙정렬과 충돌)
- 헤더 표 `<hp:sz width>` > printW면 열폭 비례 축소: 행마다 누적합에 배율을 곱해
  반올림하는 방식(누적-반올림)으로 각 `<hp:cellSz width>`를 재계산 → 행 합계가 정확히
  같아지게 한다. 표 sz width도 동기화.

## 3단계 — 헤더 표와 본문 표 사이 간격(GAP) 결정 후 전 섹션 고정
- 정의: `GAP = margin@header밴드 − 헤더표높이 + (본문 첫 요소의 상단 여백)`
- 후보를 좁은 순서로 시험: **283(1mm) → 425(1.5mm) → 566(2mm) → 850(3mm)** HWPUNIT
- 각 후보에 대해 한컴으로 **전 페이지 렌더**하여 (a) 헤더 표와 본문 표의 테두리가 붙거나
  겹치지 않고 (b) 두 표 사이의 텍스트(■ 작성일, ◆ 년도 등)가 가려지지 않는 **최소값**을 채택
- 적용: 전 섹션에 `margin@header = 헤더표높이 + GAP`, 본문 첫 문단 위 여백 0
- 최종 채택 GAP 수치를 보고서에 명시 (기준 파일의 현재 슬랙은 400)

## 4단계 — 본문 표 중앙정렬 (헤더와 같은 중앙축)
본문 최외곽 표 전부:
- `treatAsChar="0" flowWithText="1" allowOverlap="0" holdAnchorAndSO="0"
  vertRelTo="PARA" vertAlign="TOP" horzRelTo="COLUMN" horzAlign="CENTER" horzOffset="0"`
- `textWrap="TOP_AND_BOTTOM"` 유지, `pageBreak="CELL"` 유지(없으면 지정)
- 앵커 문단의 들여쓰기 공백 run 제거 (남기면 중앙에서 밀린다)

## 5단계 — 본문 표를 printable region 내 최대 크기로
각 본문 최외곽 표:
- **폭**: 표 sz width가 bodyW가 되도록 열폭 누적-반올림 비례 확대/축소 (2단계와 동일 기법)
- **높이**: 표높이 ≤ bodyH면 행높이(`cellSz height`)를 누적-반올림 비례 확대해 합계 = bodyH.
  표높이 > bodyH면 높이는 건드리지 말고 `pageBreak="CELL"`로 페이지 분할에 맡긴다.
- 한 섹션에 본문 표가 여러 개(다중 페이지 인스턴스)면 각 표를 개별로 위 규칙 적용.
  단, 작은 보조 표(높이 < bodyH의 30%: 서명란·목표항목 등)는 폭만 맞추고 높이는 확대 금지.
- `cellSz height`는 최소높이 개념이므로 텍스트가 넘치면 자동으로 늘어난다 — 확대만 안전,
  축소는 금지.

## 6단계 — 헤더·본문 상호 간섭 금지 (불변식)
- `margin@header ≥ 헤더표높이 + GAP` (assert)
- `margin@footer(3400) ≥ 꼬리말 내용높이` — 꼬리말은 구분선+라벨 2줄 ≈ 3304 → 3400 유지
- 본문 표 전부 `allowOverlap="0"` + `flowWithText="1"` (쪽 영역 안쪽 제한)
- 머리말 subList `vertAlign="TOP"`, 꼬리말 subList `vertAlign="BOTTOM"` 유지

## 최종 검증 (모두 PASS해야 납품)
1. XML 정형성: 전 섹션 + header.xml + content.hpf + container.rdf
2. 스타일 참조: charPr/paraPr/style/borderFill dangling 0
3. 텍스트 패리티: 작업 전후 `<hp:t>` 정규화 멀티셋 동일 (공백 run 제거분 제외)
4. 기하 assert: 전 본문 표 width == bodyW(±2), 헤더 표 width ≤ printW,
   margin@header == 헤더표높이+GAP
5. zip 게이트: mimetype 선두 STORED, 엔트리 순서 보존, CRC OK
6. 한컴 렌더: 전 페이지 스크린샷 — 표가 페이지 밖으로 나가는 페이지 0,
   헤더/본문 겹침 0, 꼬리말 최하단 고정 확인
7. 보고서: 섹션별 (printW, bodyH, 헤더표 w×h, 본문표 w×h 변경 전→후, 채택 GAP) 표
